# Auto-import de stages

Deja aqui archivos `.zip` o `.rar` de stages y IKEMEN-GO los agregara automaticamente al listado de stages al iniciar.

Notas:
- No hace falta editar `select.def` para estos paquetes.
- Si el mismo archivo ya esta referenciado manualmente en `select.def`, no se duplica.
- El motor intentara encontrar el `.def` principal dentro del archivo usando las mismas reglas del auto-import de personajes.
